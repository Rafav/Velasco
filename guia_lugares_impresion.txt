RECOMENDACIONES PARA LUGARES DUDOSOS
================================================================================

1. "ibid" → SIEMPRE verificar entrada anterior del mismo autor

2. Errores OCR comunes:
   - "rn" ↔ "m"
   - "cl" ↔ "d"
   - "ii" ↔ "u"
   - "nn" ↔ "m"
   - "l" ↔ "I" (i mayúscula)

3. Abreviaturas comunes:
   - "Lugd." = Lugduni (Lyon)
   - "Compl." = Compluti (Alcalá)
   - "Hispal." = Hispali (Sevilla)
   - "Valent." = Valentiae (Valencia)
   - "Barcinon." = Barcinone (Barcelona)

4. Ciudades multilingües:
   - Ginebra: Genève, Geneva, Genevæ, Coloniae Allobrogum
   - Estrasburgo: Strasbourg, Straßburg, Argentoratum, Argentorati
   - Colonia: Köln, Cologne, Colonia Agrippina

5. Contexto temporal:
   - Pre-1500: Predominan Venecia, Roma, París, Lyon
   - 1500-1600: Auge de Amberes, Basilea, Alcalá
   - 1600-1700: Predominio español (Madrid, Sevilla, Zaragoza)
   - 1700-1800: Madrid, París, Amsterdam
